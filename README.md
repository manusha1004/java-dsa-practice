\# Java DSA Practice



A beginner-friendly Java programming repository focused on problem-solving and technical interview preparation.



\## Programs Included



1\. \*\*Hello World\*\* – Basic Java syntax and output.

2\. \*\*Even or Odd\*\* – Conditional statements and modulus operator.

3\. \*\*Prime Number\*\* – Loops and number checking.

4\. \*\*Palindrome Number\*\* – Number reversal and comparison.



\## Technologies Used



\- Java

\- Visual Studio Code

\- Git

\- GitHub



\## How to Run



Make sure Java JDK is installed on your computer.



Compile and run a program using:



```bash

javac EvenOdd.java

java EvenOdd

```



Replace `EvenOdd` with the corresponding class name to run another program.
